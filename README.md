# Aegis-Claw: Autonomous DeFi Escape Pod

> 🚧 Built for Clawathon Tokyo Edition. 
> An autonomous agent that protects your assets from DeFi hacks and liquidity collapse.

## 🚀 Overview (プロジェクト概要)
Aegis-Claw is an AI-driven agent built on **OpenClaw (ISEAI)**. It monitors the DeFi ecosystem and executes emergency asset evacuation using **Jupiter (Solana)**. It acts as an "Emergency Brake" when human reaction is too slow.

Aegis-Clawは、**OpenClaw (ISEAI)** 上で動作するDeFi資産防衛のための「自動緊急脱出装置」です。ハッキングや流動性枯渇といった致命的なリスクに対し、AIが自律的に反応し資産を安全圏へ避難させます。

## 💡 The Problem (解決する課題)
In today's DeFi, liquidity can vanish in minutes during a hack. By the time a human notices, it's often too late to sell.

DeFiの戦場では、数分のハッキングで流動性が枯渇します。人間が異変に気づいた時には、すでに資産は引き出せなくなっています。

## 🛠️ Key Features (主な機能)
1. **Autonomous Reasoning:** Evaluates security alerts and market news in real-time. (AIによる自律的判断)
2. **One-Shot Execution:** Triggers instant asset evacuation to a secure vault using Jupiter's optimized routing. (緊急避難の自動執行)
3. **No Human Intervention:** Removes human hesitation from the loop during panic. (人間による介在を排除)

## ⚙️ Technical Stack (技術スタック)
- **AI Agent Framework:** OpenClaw (ISEAI)
- **Reasoning Engine:** Google Gemini (via AI Studio)
- **Execution Layer:** Solana Devnet / Jupiter API (v6)
