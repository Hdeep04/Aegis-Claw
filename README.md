# Aegis-Sui: Autonomous DeFi Escape Pod

> 🚧 Built for Clawathon Tokyo Edition. 
> An autonomous agent that protects your assets from DeFi hacks and liquidity collapse.

## 🚀 Overview (プロジェクト概要)
Aegis-Sui is an AI-driven agent built on **OpenClaw (ISEAI)**. It monitors the DeFi ecosystem and executes emergency asset evacuation using **Sui Testnet**. It acts as an "Emergency Brake" when human reaction is too slow.

Aegis-Suiは、**OpenClaw (ISEAI)** 上で動作するDeFi資産防衛のための「自動緊急脱出装置」です。ハッキングや流動性枯渇といった致命的なリスクに対し、AIが自律的に反応し資産を安全圏へ避難させます。

## 💡 The Problem (解決する課題)
In today's DeFi, liquidity can vanish in minutes during a hack. By the time a human notices, it's often too late to sell.

DeFiの戦場では、数分のハッキングで流動性が枯渇します。人間が異変に気づいた時には、すでに資産は引き出せなくなっています。
